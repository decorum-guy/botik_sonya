# Запуск тестов прямо из Roadmap Studio

Для тестов больше не нужен отдельный `python3 -m http.server`.

Запусти из корня проекта:

```bash
python -m tools.builder_server
```

Команда одновременно:

- запускает Telegram-бота с настройками из `.env`;
- использует указанный `PROXY_URL`;
- поднимает Roadmap Studio на `http://127.0.0.1:8080/builder/`;
- обычно сама открывает страницу в браузере.

Если порт 8080 занят старым HTTP-сервером, останови его через `Ctrl+C`.

## Подключение тестового аккаунта

После запуска сервера отправь боту `/start` со второго Telegram-аккаунта, который изображает участницу. В редакторе индикатор сменится на «Тестовый аккаунт подключён».

## Кнопки запуска

- **Весь сценарий** — запускает текущий черновик с `meta.entry_step_id`.
- **Выбранный этап** — запускает этап, выделенный на схеме, с первого блока.
- **Выбранный блок** — запускает только выделенный блок и останавливается после него.

Редактор отправляет серверу текущий черновик из браузера. Экспортировать и вручную заменять `roadmap/quest.json` перед каждым тестом не требуется.

Для одиночного блока переходы после ответа и кнопок временно отключаются, чтобы тест не ушёл дальше по сценарию. Сам блок `goto` отдельно не запускается, потому что он ничего не отправляет; для него используй запуск этапа.

## Важное ограничение

`python -m tools.builder_server` предназначен для редактирования и тестов. Обычный боевой запуск по-прежнему выполняется командой:

```bash
python -m app.main
```

Не запускай оба процесса одновременно с одним Telegram-токеном: два процесса начнут конкурировать за Telegram polling.
