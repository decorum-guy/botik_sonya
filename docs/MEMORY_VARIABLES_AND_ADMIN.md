# Администратор по паролю и переменные воспоминаний

## Настройка `.env`

Скопируй значения из `env.example.v2` в `.env` и заполни минимум:

```dotenv
BOT_TOKEN=...
ADMIN_PASSWORD=длинный-случайный-пароль
PROXY_URL=socks5://user:password@host:port
```

`ADMIN_TELEGRAM_ID` больше не нужен. Старое поле можно удалить.

## Первый запуск и тестовый аккаунт

1. Запусти бота: `python -m app.main`.
2. Со своего основного Telegram-аккаунта отправь `/admin твой-пароль`.
3. Бот по возможности удалит команду с паролем и сохранит твой Telegram user ID в SQLite как единственного администратора.
4. На втором аккаунте отправь `/start`. Этот аккаунт будет играть роль Сони.
5. Бот ответит `Бот активирован`; для финального сценария эти два сообщения можно удалить вручную.

Повторный ввод правильного пароля с другого аккаунта не перезапишет администратора.

## Как работают переменные воспоминаний

В Roadmap Studio добавляй блок `Воспоминание` именно в ту точку, где реконструкция должна проиграться. Поле `memory_id` является именем переменной.

Пример:

```text
first_chat
first_date
car_night
```

Если `first_chat` встречается в ROADMAP три раза, это одна переменная и одно сохранённое воспоминание, которое проигрывается в трёх местах. Порядок первого появления переменных в ROADMAP определяет порядок мастера заполнения.

После `/admin <пароль>` бот автоматически:

1. читает `roadmap/quest.json`;
2. находит все уникальные `memory_id`;
3. проверяет, какие из них уже заполнены в SQLite;
4. запускает заполнение первой отсутствующей переменной;
5. после `/memory_done` автоматически переходит к следующей.

Во время заполнения пересылай настоящие сообщения из вашей переписки в нужном порядке. Обычные заново набранные сообщения бот не принимает, потому что они не сохранят `Forwarded from`.

Команды:

```text
/memory_setup   — начать или продолжить мастер
/memory_done    — сохранить текущую переменную и перейти к следующей
/memory_status  — показать прогресс N/X
/memory_preview <id> — проверить пересылку на своём аккаунте
/memory_play <id>    — отправить участнице
```

`/start_quest` и `/start_quest_now` не запустят квест, пока хотя бы одна переменная из ROADMAP остаётся пустой.

## Что хранится где

- `roadmap/quest.json`: только сюжет, действия и `memory_id`;
- `data/bot.db`: ID администратора, ID участницы, таймер, состояние квеста и Telegram message ID воспоминаний;
- `.env`: токен, пароль и прокси;
- GitHub: код и неперсональные медиа, которые ты сознательно коммитишь.

Не коммить `.env`, `data/bot.db` и приватную переписку в публичный репозиторий.
